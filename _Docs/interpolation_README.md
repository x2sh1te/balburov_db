# Интерполяция

Основа: feature/plpgsql-scripts. Новая ветка: feature/interpolation.
1. Один раз выполнить scripts/interpolation_setup.sql.
2. Выполнить scripts/interpolation_tests.sql. Сохранить скриншоты вкладок Messages (проверки DO) и Data Output (расчет).

Использован новый образец ТЗ: (0,0.5), (5,0.5), (10,1), (20,1), (25,2), (30,3.5), (40,4.5). Он отличается от прошлого источника: прежняя temperature_corrections не меняется. Новый точечный справочник interpolation_corrections исключает неоднозначность диапазонов.
При 26 °C точки (25,2) и (30,3.5), результат 2.3.
При 23 °C по НОВОМУ образцу результат 1.6, а не 1.8 из прошлого источника.

Принятое граничное правило: ниже 0 поправка 0 по прежнему указанию «Ниже 0»; выше 40 поправка постоянна 4.5 (без экстраполяции). Само новое ТЗ требует учесть границы, но не задает конкретный способ обработки. В нуле поправка 0.5, поэтому имеется разрыв относительно отрицательных температур. Правило явно зафиксировано, а не выведено из линейной формулы.
При точном совпадении с табличной температурой возвращается одна точка дважды. При x0=x1 и y0=y1 функция возвращает константу, не делит на ноль. Это также используется для внешних границ. NULL и некорректные структуры отклоняются.

Коммит и отправка выполняются после отдельного согласования.
