# Анализ базы Front

## Анализ закупки продукции.

**Основные таблицы**

`bm_JournalBarnetDocs` — `ID`, ключ документа. Пример — 388238.
`bm_StorageOperations` — `DocumentID`, ключ документа поступления. Пример — 388238.

**Связанные таблицы**

`bm_JournalTypeDocuments` — `Description`, название типа документа. Пример — Поступление продуктов.
`bm_StorageOperationsType` — `Description`, название складской операции. Пример — Поступление.
`product` — `description`, название товара. Пример — Ветчина.
`size` — `ID`, единица учёта для `bm_StorageOperations.RangeID`. Пример — 42 (кг).

## Анализ продажи товара.

**Основные таблицы**

`journal` — `id`, артикул товара в чеке. Пример — 271363.

**Связанные таблицы**

`transtype` — `transtypeid`, код типа транзакции. Пример — 101 (продажа).
`product` — `productid`, артикул для связи с `journal.id`. Пример — 271363.

## Анализ взаимоотношений с поставщиками.

**Основные таблицы**

`vendors` — `id`, ключ поставщика. Пример — 107 (Овощи Сатурн).
`bm_StorageOperations` — `VendorID`, ключ поставщика из `vendors.id`. Пример — 107.

**Связанные таблицы**

`vendorgroup` — `description`, название группы поставщиков. Пример — Поставщики.
`bm_JournalBarnetDocs` — `ID`, ключ документа поступления. Пример — 465800.
`bm_JournalTypeDocuments` — `Description`, название типа документа. Пример — Поступление продуктов.
`product` — `id`, ключ товара. Пример — 7246 (Салат листовой).

## Анализ работы персонала.

**Основные таблицы**
`personnel` — `personid`, ключ сотрудника. Пример — 1029.
`journal` — `loginid`, идентификатор для связи с `personnel.personid`. Пример — 1029.

**Связанные таблицы**
`transtype` — `description`, название события. Пример — Начало работы.

## Анализ остатков.

**Основные таблицы**

`bm_StorageOperations` — `Count`, изменение количества со знаком. Пример — −0.1200.

**Связанные таблицы**

`bm_JournalBarnetDocs` — `Period`, дата складского документа. Пример — 30.11.2023.
`bm_StorageOperationsType` — `Description`, тип складского движения. Пример — Списание.
`storages` — `id`, ключ склада. Пример — 41 (Склад).
`product` — `productid`, артикул товара. Пример — 4603796.
`size` — `ID`, единица учёта для `bm_StorageOperations.RangeID`. Пример — 42 (кг).
