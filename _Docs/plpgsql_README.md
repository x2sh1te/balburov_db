# PL/pgSQL: метеобаза

Ветка feature/plpgsql-scripts создана от feature/data-analysis.

## Выполнение
1. Запустить Docker Desktop и дождаться готовности PostgreSQL.
2. Открыть Query Tool существующей базы.
3. Выполнить scripts/plpgsql_setup.sql один раз целиком.
4. Ожидается таблица поправок из семи строк. Сохранить скриншот.
5. Выполнить scripts/plpgsql_metadata.sql. Сохранить результат.
6. Обновить дерево Schemas в pgAdmin: появится meteo_plpgsql.
7. Через ERD Tool построить диаграмму таблиц только этой схемы, сохранить файл проекта ERD и скриншот в _Docs/plpgsql/.

Скрипт создает новую версию предыдущей метеосхемы: 10 таблиц и 10 явных последовательностей. Существующие данные public сохраняются.
Три отдельные транзакции: структура и счетчики; данные; связи и ограничения. Основная работа выполнена в PL/pgSQL DO-блоках.
При ошибке внутри транзакции выполнить ROLLBACK. Не запускать весь файл повторно вслепую: предыдущие транзакции могли уже завершиться.

## Таблица 1
| t0 | Поправка |
|---|---|
| Ниже 0 | 0 |
| 0–5 | 0.5 |
| 10–15 | 1 |
| 20 | 1.5 |
| 25 | 2 |
| 30 | 3.5 |
| 40 | 4.5 |

Формулы источника: T0 = t0 + поправка; отклонение = T0 - 15.9.
В temperature_corrections сохранены исходные диапазоны и точки. Для строки «Ниже 0» верхняя граница исключительная; для остальных диапазонов границы включительные. Правила для пробелов и значений выше 40 не придуманы. Автоматический расчет не реализован: текущий пункт требует таблицу с данными.
Поправка процентов не имеет базовой единицы в таблице компонентов: процент безразмерен. Связь Цельсия с кельвином описывает размерность, а не полный перевод шкалы.

## Проверка
Проверка форматирования git diff --check пройдена. Все три PL/pgSQL-блока и запрос метаданных успешно выполнены в PostgreSQL в общей проверочной транзакции с ROLLBACK. Получены 7 поправок, 10 таблиц, 10 последовательностей и 8 внешних ключей. Отдельные COMMIT исходного файла в этой проверке не выполнялись.
